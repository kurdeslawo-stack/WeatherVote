# WeatherVote

Plugin do głosowania na zmianę czasu i pogody na serwerach Minecraft.

Repozytorium zostało utworzone z zachowanego kodu źródłowego pierwotnej wersji pluginu. Aktualny etap to import i uporządkowanie źródeł przed przygotowaniem publicznego wydania.

Plan dalszych prac:

- konfiguracja języka przez `language:`,
- osobne pliki `lang_pl.yml` i `lang_en.yml`,
- przeniesienie wszystkich tekstów z kodu do plików językowych,
- uporządkowanie nazewnictwa i konfiguracji,
- możliwie szeroka kompatybilność ze starszymi wersjami Minecrafta,
- przygotowanie pod publikację na Modrinth / SpigotMC.

> `config.yml` i `plugin.yml` z oryginalnej wersji nie zostały jeszcze zaimportowane.
